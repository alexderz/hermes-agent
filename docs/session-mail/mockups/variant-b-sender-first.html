session-mail mockup B — sender first (intercom's order)

DER-701 · Spec mockups · 2026-11-10 · one exchange on every surface. Other variants: A — “Not Alex” first (as in ux.md) C — two-line card · README
Header shape. One header line in intercom's order: 📡 hermes@<title> first, “not Alex” inside the brackets, then the reply label and the id. This is the HLD's D2 example.
Reply matcher anchor this implies. A line that starts 📡 hermes@ and ends · message <id>:.
Fixed in every variant (ux.md): authority line, interrupt line, footer, closing line 📡 End of message <id>, relabelling of body lines starting with 📡.
The exchange.
  1. 1“Hermes Improvement — Orchestrator” sends a steered mail (3f2a9c) into Alex's running turn with “Budgeting — Orchestrator”.
  2. 2Budgeting answers Alex, with a [REPLY 3f2a9c] block for the mail.
  3. 3The block arrives back in Hermes Improvement as mail 8e41b0 (“reply optional”).
  4. 4Later, Hermes Improvement sends with delivery="interrupt" (5b77e1); receipt: interrupted (redirect).
  5. 5Hermes Improvement's answer ends [REPLY 8e41b0][SILENT][/REPLY]: nothing is sent.
Neutral colours only; every status chip is a word. Alex's bubbles and mail bubbles share one colour on the phone on purpose (SM-Q11, accepted).
