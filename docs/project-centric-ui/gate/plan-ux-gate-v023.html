3 · What gets built

Main-chat fieldOne optional field per project (owner_session_id). Small core patch, same as planned on v0.22; the gateway passes it through unchanged. Session Mail's @project will read it.
Webapp sidebarSmall core edit (plugins can't hook project rows): the tap opens the main chat, the main chat is listed first and marked, even when pinned. Code moves out of the oversized sidebar file, so it gets smaller.
Set the main chatsNew command hermes project set-owner <project> <session-id> (and --clear), with an undo file. Run once for the six: five "XXX - Orchestrator" chats plus "MDL - Model Master". Pins unchanged.
/new in a main chatOnly if you say yes (PUI-Q2): a small fork plugin copies Bot Chat's rule, so /new compacts the main chat in the Webapp. The command line keeps plain /new.
DeployPull, rebuild the Webapp bundle, then one drain-first gateway restart: it waits (up to 30 minutes) for running turns, scheduled when no main-chat turn is running. Reload the Webapp, or reopen the home-screen copy.
